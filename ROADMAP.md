# 🍫 TrufaMia — Roadmap & Future Development

> This document outlines the planned evolution of the TrufaMia order management system,
> from short-term improvements to long-term data analytics and business intelligence.

---

## Current State (v6 — May 2026)

The system currently handles the full order intake pipeline:

- ✅ Structured email parsing (Gmail → Google Sheets)
- ✅ Field validation with automatic error reply
- ✅ Auto-generated order IDs
- ✅ Sales analytics (units per flavour, revenue per box type)
- ✅ Customer records auto-updated on each processing run
- ✅ Stock tracking with low-stock alerts
- ✅ Visual flavour selector sidebar (manual order entry)
- ✅ Manual processing mode via custom Sheet menu

## Phase 1 — Data Collection (Now → 3 months)

> **Goal:** Build a clean, consistent dataset before adding analytics.

The most important phase is often the least visible: collecting good data.
Without enough orders recorded, any analysis would be misleading.

### Actions
- [ ] Process all incoming orders consistently through the pipeline
- [ ] Validate that customer records are being built correctly in CLIENTES
- [ ] Review and fix any edge cases in email parsing (unusual formats, typos)
- [ ] Standardise flavour names across all incoming orders

### Why this matters
Every analytical technique — trend detection, customer segmentation, demand forecasting —
depends entirely on the quality and volume of the underlying data.
**Garbage in, garbage out.**

## Phase 2 — KPIs & Reporting (3–6 months)

> **Goal:** Turn raw order data into actionable business insights.

### Key metrics to track

| KPI | What it tells us | How to calculate |
|---|---|---|
| Weekly revenue | Business growth trend | SUM of Precio by week |
| Average order value | Pricing effectiveness | AVG of Precio |
| Top 5 flavours | What to produce more of | COUNTIF on Sabores |
| Customer return rate | Loyalty / satisfaction | % Repetidor vs Nuevo |
| Best acquisition channel | Where to focus marketing | COUNTIF on Canal |
| Revenue per channel | ROI by channel | SUM Precio grouped by Canal |

### Deliverables
- [ ] Dashboard tab in Google Sheets with charts (revenue trend, flavour ranking, channel split)
- [ ] Automated weekly summary email — sent every Monday with previous week's numbers
- [ ] Monthly PDF report generated by script (extending `generar_guia.py` pattern)

## Phase 3 — Customer Intelligence (6–12 months)

> **Goal:** Understand customers well enough to personalise and retain them.

### Analyses planned

**Recurrence analysis**
- Which customers order every week vs occasionally?
- What is the average time between orders per customer?
- Who hasn't ordered in 30+ days? (churn risk)

**Segmentation**
- Wholesale vs individual customers — different behaviour patterns
- High-value customers (top 20% by spend)
- Channel preference by customer segment

**Flavour affinity**
- Which flavours are always ordered together?
- Do customers stick to the same flavours or experiment?
- Which flavours drive the highest basket value?

### Marketing applications
- Targeted reactivation: identify dormant customers and trigger a personalised outreach
- Upsell opportunities: customers who always order 8-unit boxes → suggest 15-unit
- Seasonal demand: which flavours peak at Christmas, Valentine's Day, summer?
- Social media strategy: promote underperforming flavours, leverage top sellers

## Phase 4 — Web Presence (TrufaMia.com)

> **Goal:** Give TrufaMia a professional digital storefront.

### Planned features

**Public site**
- Brand landing page (story, product photos, contact)
- Interactive flavour catalogue with descriptions
- Pricing table

**Order form**
- Web-based order form replacing the email template
- Form validation matching current pipeline rules
- Direct write to Google Sheets via Apps Script Web App (no email needed)
- Automatic confirmation email to customer

**Tech stack options**
- Simple: HTML/CSS/JS static site + Google Apps Script Web App as backend
- Advanced: Next.js frontend + Supabase or Firebase as database

## Phase 5 — Advanced Analytics & Automation (12+ months)

> **Goal:** Build a data infrastructure that scales with the business.

### Data pipeline evolution

```
Current:
Email → Apps Script → Google Sheets

Future:
Web form / WhatsApp → API → Database (PostgreSQL) → Analytics layer
```

### Tools under consideration

| Tool | Purpose |
|---|---|
| **Looker Studio** | Free visual dashboards connected to Google Sheets |
| **Power BI** | More powerful dashboards if data volume grows |
| **Python (pandas)** | Deeper analysis — cohort analysis, trend modelling |
| **WhatsApp Business API** | Direct order intake via WhatsApp (no email needed) |
| **PostgreSQL / Supabase** | Relational database when Sheets hits its limits |

### Analyses at scale
- Demand forecasting by week and season
- Customer lifetime value (CLV) prediction
- Cohort analysis: do customers acquired via Instagram behave differently than WhatsApp?
- Price elasticity: does a price change affect order volume?
